## 🚀 Running the Project

Clone the repository:

```bash
git clone https://github.com/jenicajudith/react-practice.git
```

Navigate to the project:

```bash
cd react-practice
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
